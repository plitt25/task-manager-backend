# Configurar backend task manager
1. clona el proyecto e ingresa a la carpeta que se genero
   https://github.com/plitt25/task-manager-backend.git
   cd task-manager-backend
3. Instalar dependencias
   npm install
4. iniciar servidor
   npm run dev
5. consume al aplicativo por el local host
   http://localhost:3000/

# Justificacion de elecciones técnicas
Node.js con Express lo tome para el backend debido a su rendimiento no bloqueante y facilidad de integración con postgresql, ideal para la creacion de Apis ligeras y rapidas de montar
